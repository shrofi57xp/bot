إعداد النشر على Netlify
========================

1) ارفع محتويات هذا المجلد إلى مستودع Git واربطه بموقع Netlify.
2) من Netlify: Site configuration > Environment variables أضف:
   TELEGRAM_BOT_TOKEN = توكن بوت جديد (لا تضعه داخل HTML أو Git)
   TELEGRAM_CHAT_ID = رقم المحادثة/القناة التي سيصلها إشعار التدريب
3) أعد نشر الموقع بعد إضافة المتغيرات.
4) افتح الموقع وجرّب النموذج. سيصل إشعار بالحدث وعنوان IP فقط.
5) احصل على Chat ID من محادثة البوت بعد بدء المحادثة معه، أو استخدم طريقة
   موثوقة لإدارة وجهة الإشعارات.

ملاحظات أمان وخصوصية:
- هذا الإصدار لا يرسل الاسم التجريبي أو الرمز أو البريد أو أي قيم حقول.
- لا توجد حقول لكلمة مرور أو رقم وطني أو رقم حساب.
- عنوان IP معلومة قد تُعرّف بالمشارك؛ احتفظ به فقط بموافقة واضحة ولغرض محدد،
  وحدد مدة الاحتفاظ به وامسحه بعدها.
- لا تضع Bot Token في JavaScript أو HTML؛ خزّنه كمتغير بيئة في Netlify.
- التوكن الذي سبق إرساله في المحادثة يجب اعتباره مكشوفاً وإلغاؤه/تدويره
  عبر BotFather قبل استخدام أي إعداد جديد.
